# Gitee 与 GitHub 同步

日常只使用 `Sync-Repositories.ps1`。桌面只保留一个入口 `All_sync`，双击后依次同步 Study、SCI、Project，把本地文件提交并推送到两个平台，窗口保留供查看结果。

| 仓库配置 | 本地来源 | Gitee | GitHub | 可见性 |
| --- | --- | --- | --- | --- |
| Study | 脚本所在文件夹，目前是 `D:\Study\learningplan2026` | [Study，实际路径 zbq](https://gitee.com/zhu-bingquanzheling/zbq) 的 `learningplan2026/` | [Study](https://github.com/Zljtling/Study) 的 `learningplan2026/` | 公开 |
| SCI | `D:\Study\scientific research project` | [SCI](https://gitee.com/zhu-bingquanzheling/sci) 根目录 | [SCI](https://github.com/Zljtling/SCI) 根目录 | 私有 |
| Project | `D:\Projects` | [Project](https://gitee.com/zhu-bingquanzheling/project) 根目录 | [Project](https://github.com/Zljtling/Project) 根目录 | 公开 |

SCI 本地目录当前为空，空目录没有 Git 提交；放入文件后运行即可提交到两个私有仓库。需要只同步其中一个仓库时，可用下方命令指定 `-Repository`，无需额外桌面快捷方式。

## 同步行为

- 本地文件为同步依据，添加、修改和删除都会同步。Study 仅更新 `learningplan2026/`，保留仓库根目录的其他文件。
- 两个平台使用同一个 `main` 分支提交；不会产生两份不同的提交历史。
- 使用已有 Git 登录和作者信息，脚本中不保存密码或令牌。
- Git 未显式配置代理、也未设置代理环境变量时，脚本会沿用 Windows 已启用的代理访问 GitHub，仅对本次运行生效。使用本地代理时须保持对应代理程序运行。
- 连接重置、超时等临时网络错误最多尝试三次；登录失败、权限错误或提交冲突不会按网络错误重试。网络恢复后重新运行 `All_sync` 即可。
- 默认只选择源码、项目配置、文档、小型图片及音频等核心文件，同时遵循各级 `.gitignore`。具体文件类型集中在脚本的 `Get-CoreFilePolicy` 中。
- 单文件默认上限为 **10 MiB**。压缩包、视频、安装包、编译产物、模型权重及缓存不上传，超过大小上限的素材也会排除。
- 排除 IDE 缓存、虚拟环境、依赖目录、Debug/Release、x64/x86、bin/obj、build/dist、outputs/demo 和 Godot 导入缓存。项目的源码、配置、场景和小型素材保留。
- 新规则会从两平台的最新版本删除不再符合条件的文件，本地原件保留。远程是精简源码备份，运行游戏所需的大型音视频素材仍需使用本地副本。
- 日志会显示精简前后的文件数和内容大小。这是最新文件树的大小，不是 Git 历史或平台实际占用；删除最新版本文件不会自动清除旧提交中的大文件。
- 某个平台推送失败，已生成的提交保存在本地缓存。重新运行相同入口，会继续把同一个提交补推到另一平台。
- 若两个平台出现分叉提交，脚本停止并报告，需先处理冲突，不会强制覆盖。
- 不在后台自动运行，也不会自动传播直接在网站上进行的修改。

缓存和日志保存在 `%LOCALAPPDATA%\GitDualSync`。缓存用于加速后续同步并保留未推送成功的提交，存在同步失败时不要删除缓存。临时快照清理失败只显示警告，不会把上传成功报告为失败。

## 手动使用

```powershell
# 预览，不提交或推送
powershell -NoProfile -ExecutionPolicy Bypass -File .\Sync-Repositories.ps1 -Repository Study -Preview

# 提交全部三个来源
powershell -NoProfile -ExecutionPolicy Bypass -File .\Sync-Repositories.ps1 -Repository All -Message "更新学习和项目文件"
```

`-IncludeIgnored` 只影响 `.gitignore`，不会绕过核心文件类型、目录排除或大小限制。通常不需要这个选项。可通过 `-MaxFileSizeMB` 调整单文件阈值，默认 10。
